Kirchhoff's rules

Two rules solve every DC circuit: charge doesn't pile up at a junction, and the voltage changes around any closed loop add to zero. Everything else (series, parallel, voltage dividers) is a shortcut built from them.

The intuition

Think of a circuit as a hiking trail map. A battery lifts you up a hill (raises the potential). Each resistor is a downhill slope that uses up some of that height. Go all the way around any closed loop and you must end up at the same height you started: the sum of the voltage changes around a loop is zero.

Charge is conserved, so at any junction the current flowing in equals the current flowing out. Water in a pipe: no matter how the pipe branches, what goes in comes out.

In a series circuit there is a single path, so the same current flows through every resistor, and the voltages add. In parallel there are separate paths between the same two points, so each branch has the same voltage, and the currents add. For anything fancier (two batteries, a bridge), write the junction and loop equations and solve.

Try this

Predict what will happen first. Then set it up and check.

  1. Compare series and parallel with the same three resistors.

    What you should see

    Series: R = 22 Ω, a single 0.55 A everywhere, and the biggest resistor takes the biggest voltage. Switch to parallel: the equivalent resistance falls to 2 Ω (less than the smallest), each resistor gets the full 12 V, and the battery supplies 6 A.

  2. In parallel, make R₁ tiny (1 Ω) and R₃ large (20 Ω).

    What you should see

    The small resistor draws most of the current. Adding another parallel path always lowers the total resistance.

  3. Open the two-battery circuit. Make ε₂ negative.

    What you should see

    The second battery now opposes the first. The current through it reverses direction: the arrow flips. A battery can be charged by another one.

  4. In the two-battery circuit, set ε₂ = 12 V with the same ε₁.

    What you should see

    Perfectly symmetric: each battery supplies the same current, and I₃ = I₁ + I₂ by the junction rule.

Worked example

In the circuit shown, ε₁ = 12 V, ε₂ = 6 V, R₁ = 4 Ω, R₂ = 2 Ω and R₃ = 6 Ω. Find the current in each branch and say which way it flows.

Try it yourself first, then reveal one step at a time.

  1. Label unknowns and guess directions. Let I₁ and I₂ flow up through the batteries and I₃ down through R₃. If a result comes out negative, the real current goes the other way.
  2. Junction rule (top node). I1 + I2 = I3.
  3. Loop rule, left loop (up through ε₁, down through R₃). 12 − 4I1 − 6I3 = 0. Going with the guessed current through a resistor is a drop (−IR).
  4. Loop rule, right loop. 6 − 2I2 − 6I3 = 0.
  5. Solve. From the loops, I1 = 3 − 1.5I3 and I2 = 3 − 3I3. Put these in the junction rule: 6 − 4.5I3 = I3, so I3 = 1.09 A, I1 = 1.36 A, I2 = −0.27 A.
  6. Interpret. I₂ is negative: the 6 V battery is being pushed backward, with 0.27 A flowing down through it. The stronger battery is charging it.
  7. Check with the top-node voltage. Vtop = I3(6) = 6.55 V. Then I1 = (12 − 6.55)/4 = 1.36 A ✓ and I2 = (6 − 6.55)/2 = −0.27 A ✓.

Common mistakes

  • Mixing up the sign: going through a resistor with the current is a drop; going through a battery from − to + is a rise.
  • Adding currents in series or voltages in parallel. Series: same current. Parallel: same voltage.
  • Using the battery voltage for each resistor in a series chain. The voltage is shared.
  • Forgetting that real batteries have internal resistance (not included here).

The two rules

  • Junction rule (conservation of charge): at any node, the currents entering add to the currents leaving.
  • Loop rule (conservation of energy): going around any closed loop, the potential changes add to zero.
  • Sign conventions: crossing a battery from − to + is +ε; crossing a resistor in the direction of the current is −IR; against the current it is +IR.
  • Strategy: pick directions for every branch current; write one junction equation per independent node and one loop equation per independent loop until you have as many equations as unknowns.

Series and parallel shortcuts

  • Series: Req = R1 + R2 + …, same current, voltages add.
  • Parallel: 1/Req = 1/R1 + 1/R2 + …, same voltage, currents add. For two: Req = R1R2/(R1 + R2).
  • Voltage divider: two resistors in series across ε: V2 = εR2/(R1 + R2).
  • Meters: an ideal ammeter has zero resistance and goes in series; an ideal voltmeter has infinite resistance and goes in parallel.

Real batteries

  • A real battery behaves like an ideal EMF ε in series with a small internal resistance r. Delivering current I, its terminal voltage is ΔVterminal = ε − Ir.
  • With no current (open circuit) the terminal voltage equals ε. The more current you draw, the lower it gets. A short circuit draws I = ε/r.
  • To solve, treat r as one more resistor in series with the battery, and apply the same loop and junction rules.
